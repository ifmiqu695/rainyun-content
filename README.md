搜「虚拟主机购买」的人大致分两类：一类还没定下来要买什么，想先搞清楚虚拟主机、VPS、云服务器差在哪；另一类已经看好了产品，只差确认价格和下单流程。这两类问题经常被塞进同一篇「主机商推荐」里，读完还是不知道该点哪个按钮。

## 先确认你买的是哪一种「虚拟主机」

同名不同物的产品，配置和能干的事差很远。

**共享型主机**：一台物理机上切出很多份空间，CPU 和内存是抢着用的，带宽和硬盘给得相对大方。不能用 SSH，装不了自定义环境，只能用服务商提供的面板管站点。便宜、上手快，适合静态站和单 PHP 站。

**容器型主机**：本质是轻量容器，CPU、内存、带宽、硬盘都独立分配，权限接近 root。雨云的宝塔面板虚拟主机就是这一类，官方文档写的是基于 LXD 虚拟化，独享 CPU / 内存 / 带宽 / 空间——但 IP 仍然是共享的，只能使用固定的几个端口，想要全端口就得另外加独立 IP。

这两条线在雨云内部对应两种面板：

- **EP 面板（EasyPanel）**：国内 Kangle 公司开发的面板，web 服务器也是自研的 kangle（早期 B 站用过）。轻量、界面简单，只支持 PHP + 单个 MySQL 数据库，单台主机限制绑定 5 个域名。适合纯静态站或一个 WordPress。
- **宝塔面板**：不限网站数量、不限数据库和域名，支持 SSH / SFTP / 远程 MySQL，能跑 PHP、Java 等环境，预装 LNMP，自带自动备份。代价是共享 IP + 固定端口。

雨云官方文档里的建议很直接：优先选宝塔主机，新手和老手都好上手。这个建议算实在，因为它没劝你去买更贵的东西。

## 价格由四个变量决定，不止「配置高低」

同一款面板、同一个配置，价格可能差一倍，差别在这四处：

1. **机房和线路**。雨云虚拟主机目前主要在三个区域：中国宿迁（京东云 BGP，国内访问最快，带 DDoS 防御，但做网站必须先备案）、中国香港（BGP 三网直连，免备案，延迟低，带宽是短板）、美国洛杉矶 1 区（国际大带宽 AS4837，流量大但国内延迟偏高）。美国洛杉矶 2 区网络条件更好，但按官方说明主要用于云服务器，虚拟主机暂不支持。
2. **面板类型**。同样的 1 核 1G，EP 主机因为 CPU / 内存共享，价格能压到宝塔主机的一半以下。
3. **配置档位**。存储、内存、CPU 核心、带宽同步往上走。
4. **购买时长**。雨云虚拟主机的时长档是 1 个月、3 个月（9 折）、半年付（8 折）、年付（7 折）。同样的机器买一年，单价直接砍掉三成。这是最容易被忽略、也最容易省钱的一项。

顺便说清备案的边界：只有国内节点（宿迁这类）在用作域名访问的网站时需要先备案，海外节点免备案。纯做数据库、测试、学习用途，国内节点不备案也能开。

## 买完之后还得做三件事

**绑定域名**。海外节点直接改 DNS 解析指向主机即可；宿迁这类国内节点，域名要先完成 ICP 备案才能正式访问。

**装 SSL**。宝塔面板里可以直接申请并自动续期证书，浏览器地址栏的锁图标和你后面要不要担心「不安全提示」都靠它。

**设置自动备份**。雨云虚拟主机自带免费的定时备份功能，同时提供 CC 防火墙和 DDoS 防火墙，遇到攻击自动切防护、结束后切回直连。这两项在低价主机里不算标配，建议开通后马上把备份周期设上。

## 几个容易踩的坑

- **EP 主机的 5 个域名上限**。主站加备用域名加测试域名，很容易就用满。
- **共享 IP 的端口限制**。宝塔主机在共享 IP 下只能用固定端口，想用默认 80 / 443 之外的常规玩法就要加独立 IP。用 Navicat 之类工具远程连数据库时，主机地址要填 127.0.0.1、端口 3306，而不是面板里显示的远程端口，这一步最容易填错。
- **别在宝塔面板里乱改端口或面板配置**。改错可能连面板都进不去，雨云提供了修复主机功能来救场，但没必要非走一遍。
- **低价套餐的资源上限是真的会碰到**。有第三方文章在汇总知乎用户反馈时提到：雨云的价格和中文面板口碑不错，但低价档位的 CPU、内存、I/O 限制偏紧，访问量突然上来或者装了几个吃资源的插件就可能触发限速甚至被暂停，另外工单响应速度也被提到过；退款政策对特价套餐相对严格。这些说法来自用户侧反馈，不代表官方承诺，但值得你在下单前想清楚自己的流量预期。
- **不同来源的价格会打架**。雨云的促销活动频率高，第三方教程里的价格截图经常滞后半年以上。看到「立省 XX」这类数字，先去结算页对一遍。

## 谁适合买，谁不适合

适合：个人博客、学习练手、小型企业展示站、免备案需求明确的外贸小站、想在正式上云之前先花几十块跑通全流程的人。

不适合：日访问量上万的内容站、要在国内节点正式经营又不愿备案的项目、需要自定义内核或复杂环境的技术场景——这类需求直接看云服务器（雨云的 RCS 产品线，按量或固定计费，独立公网 IP、流量不限）更合适。

**问：虚拟主机和云服务器怎么选？**
只要你能接受别人规定好的面板和权限，虚拟主机便宜且省事；只要你需要独立 IP、自定义环境、随时换系统，就是云服务器的场景。

**问：免备案的虚拟主机能长期用吗？**
能，前提是域名和服务器都在境外节点。要注意的是免备案不等于免责任，内容合规要求依然存在。

**问：买了之后能升级配置吗？**
可以，雨云支持在使用期间升级套餐和续费，官方说法是 1 分钟内完成。所以起步可以买低配，跑顺了再加。

**问：新手最该先决定什么？**
顺序是机房 → 面板 → 配置 → 时长。先定机房，因为备案和延迟这两件事后面改起来最麻烦。
